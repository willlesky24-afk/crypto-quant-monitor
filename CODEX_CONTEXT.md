\# CODEX CONTEXT — Crypto Quant Monitor



\## Proyecto



Crypto Quant Monitor es un sistema de análisis cuantitativo de mercados de criptomonedas.



El objetivo del proyecto es evolucionar desde un sistema de análisis técnico hacia un motor cuantitativo capaz de evaluar condiciones de mercado, generar señales, medir riesgo, almacenar históricos y realizar validación estadística mediante backtesting.
